La aplicación funciona perfectamente en Modo Local (autoguardado en tu navegador). Para activar la nube multi-dispositivo, edita la constante CLOUD_CONFIG al inicio del <script> con tu SUPABASE_URL y SUPABASE_ANON_KEY.

Script SQL para crear la tabla mindmaps en Supabase: 
create table if not exists public.mindmaps (
  id uuid default gen_random_uuid() primary key,
  user_id uuid references auth.users(id) on delete cascade not null,
  title text not null default 'Mapa sin título',
  data jsonb not null,
  updated_at timestamptz default now() not null
);

alter table public.mindmaps enable row level security;

create policy "Usuarios gestionan sus propios mapas"
  on public.mindmaps for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
